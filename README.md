# Embodied AI for Scientific User Facilities
Learned robotic manipulation of fragile scientific specimens at DOE user facilities. Manipulation policies are trained in GPU based physics simulation on digital twins of real beamlines and transferred to robotic hardware at operating instruments, beginning at SLAC's MeV-UED facility. Software, digital twin assets, and benchmarks will be released here as the program matures.
